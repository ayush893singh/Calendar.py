# Calendar Generator

A simple and user-friendly Python Calendar Generator that allows users to view a complete year's calendar, display a specific month's calendar, and check whether a year is a leap year.

# Features

- Display complete calendar for any year
- Display calendar for a specific month
- Check whether a year is a leap year
- Handle invalid input
- Menu-driven program
- Beginner-friendly
- Uses Python's built-in "calendar" module
- No external libraries required

# Technologies Used

- Python 3
- "calendar" module
- Loops
- Conditional statements
- Exception handling
- User input

# Menu Options

Option| Function
1| Show Complete Year
2| Show Specific Month
3| Check Leap Year
4| Exit

# How to Run

1. Install Python

Make sure Python 3 is installed on your computer.

Check your Python version:

python --version

2. Clone the Repository

git clone YOUR_REPOSITORY_URL

3. Open the Project Folder

cd Calendar-Generator

4. Run the Program

python CalendarGenerator.py

Requirements

No external packages are required.

The project uses Python's built-in "calendar" module:

import calendar
